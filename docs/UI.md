# Интерфейс

Стиль — как у Impala и bluetui в Omarchy: плавающее окно, рамки со скруглёнными углами
(`BorderType::Rounded`), заголовки блоков в рамке, подсказки клавиш внизу.
Макеты ниже — ориентир по расположению, а не точные размеры.

## Цвета (только ANSI, чтобы работала тема Omarchy)

| Что | Цвет |
|-----|------|
| Заголовки блоков, выбранная вкладка, акцент | Blue |
| «Включено», галочки, сильный сигнал | Green |
| Предупреждения, новое устройство | Yellow |
| Ошибки, «выключено» | Red |
| Трафик ↓ | Cyan |
| Трафик ↑, значок изоляции | Magenta |
| Второстепенный текст, подсказки | DarkGray |
| Выделенная строка | фон DarkGray / модификатор REVERSED |

## Простой режим

```
╭─ 󰀂 Раздача Wi-Fi ─────────────────────────── [Простой]  Продвинутый ─╮
│ ╭─ Статус ───────────────────────────────────────╮ ╭─ Подключить ──╮ │
│ │ ● Раздача включена               [ ВКЛ ■■■ ]   │ │ ▄▄▄▄▄ ▄ ▄▄▄▄▄ │ │
│ │ JoK3R-PC · 5 ГГц · канал 36 · 1:24:07          │ │ █ ▄ █ ▀ █ ▄ █ │ │
│ │ [ WPA3] [изоляция] [ПК скрыт от гостей]       │ │ ▀▀▀▀▀ █ ▀▀▀▀▀ │ │
│ ╰────────────────────────────────────────────────╯ │  наведи камеру│ │
│ ╭─ Трафик ───────────────────────────────────────╮ ╰───────────────╯ │
│ │ ▁▂▃▅▆▅▇▆█▇▆▇▆█▇█   ↓ 14.2 МБ/с  ↑ 1.1 МБ/с  3.4 ГБ за сеанс        │
│ ╰────────────────────────────────────────────────────────────────────╯ │
│ ╭─ Устройства · 2 ───────────────────────────────────────────────────╮ │
│ │ 󰄜 Pixel-8     ▂▄▆█   10.42.0.34     ↓ 12 МБ/с                      │ │
│ │ 󰀷 iPhone      ▂▄▆    10.42.0.51     ↓ 0.4 МБ/с                     │ │
│ │ ⚠ Новое устройство: Galaxy-Tab — разрешить?  y / n                 │ │
│ ╰────────────────────────────────────────────────────────────────────╯ │
│ Space вкл/выкл · e изменить · p пароль · Tab режим · Esc выход        │
╰────────────────────────────────────────────────────────────────────────╯
```

- Когда раздача выключена: статус красным «● Раздача выключена», QR и трафик скрыты, вместо них подсказка «Нажми Space, чтобы включить».
- Баннер нового устройства — жёлтой пунктирной рамкой или жёлтым текстом, всегда виден.
- Пароль по умолчанию скрыт (`••••••••`), `p` показывает на 10 секунд.

## Продвинутый режим

```
╭─ 󰀂 Раздача Wi-Fi ─────────────────────────── Простой  [Продвинутый] ─╮
│ ╭─ Разделы ───────╮ ╭─ Безопасность ──────────────────────────────────╮ │
│ │ 󰖩 Радио         │ │ Защита                ◀ WPA3 (откат на WPA2) ▶ │ │
│ │ 󰒃 Безопасность ◀│ │ Защита кадров (PMF)             обязательна    │ │
│ │ 󰛳 Сеть          │ │ Изоляция устройств              [x] вкл        │ │
│ │ 󰔟 Автоматизация │ │ Доступ гостей к ПК              запрещён       │ │
│ │ 󰀂 Устройства    │ │ Одобрять новые устройства       [x] вкл        │ │
│ │ 󰒓 Эксперт       │ │ Чёрный список                   1 устройство   │ │
│ │                 │ │ Уведомления о входе             [x] вкл        │ │
│ │                 │ │ Пароль                ████████░░ надёжный      │ │
│ ╰─────────────────╯ ╰─────────────────────────────────────────────────╯ │
│ Подсказка: WPA3 — самая стойкая защита. Старые устройства подключатся │
│ по WPA2 автоматически.                                                 │
│ ↑↓ выбор · ←→ изменить · g новый пароль · s сохранить · Tab · Esc     │
╰────────────────────────────────────────────────────────────────────────╯
```

- `↑↓` — раздел; `→`/Enter — войти в параметры; в параметрах `←→` меняют значение, Enter — переключить,
  ввести своё значение или выполнить действие; `Esc` (или `←` на действии) — обратно к разделам.
- Раздел «Устройства»: `b` отобрать/вернуть интернет, `a` разрешить, `k` отключить, `o` одобрение вкл/выкл.
- Рамки по высоте содержимого, сверху строка состояния раздачи, ниже — ошибка/уведомление или «* есть
  несохранённые изменения».
- Под окном всегда подсказка к выбранному параметру (одно-два предложения на русском).
- Несохранённые изменения помечаются `*` в заголовке раздела; при выходе — вопрос «Сохранить изменения?».

## Общие правила

- Интерфейс никогда не зависает: во время долгих операций — спиннер и текст «Включаю раздачу…».
- Ошибки — внизу красной строкой простыми словами + что сделать. Никаких сырых сообщений nmcli: их — в журнал.
- Все тексты — через словари ru / uk / en.
